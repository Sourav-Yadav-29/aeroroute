Algorithms Used
1 · Dijkstra's Algorithm
Min-priority queue finds shortest paths between all node pairs. Predecessor maps reconstruct each route segment.
2 · Nearest Neighbour (Greedy)
Among feasible stops, highest-priority tier selected first, then nearest within that tier. IDs break ties.
3 · Priority Queue
Stops are queued and dispatched High → Normal → Low when Priority Scheduling is enabled.
4 · Battery Constraint
Each candidate is only committed if energy for (leg + return) fits within the usable battery budget.
